# Mehedi Hasan Sagor — Portfolio

A responsive personal portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive design and animations
- `script.js` — theme toggle, mobile menu and small interactions

## Quick customization
1. Replace `your-email@example.com` in `index.html` with your real email.
2. Add your real project links.
3. Upload the files to your GitHub repository.
4. Enable GitHub Pages to publish the site.
